# Bảng giá phụ kiện cụm shop

[Mở ứng dụng](https://lebangdinh.github.io/GIASP/app/)

Chọn **Nhập bảng giá** để đọc file Excel trên thiết bị. Kiểm tra sheet, ngày áp dụng và phạm vi shop trước khi lưu.

Để dùng bảng đã được quản lý chốt giá, mở **Quản lý cụm → Nhập gói / khôi phục** và chọn gói nội bộ được gửi riêng.
